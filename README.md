# Proyecto Egreso (Restaurante)

Este proyecto está desarrollado con un stack vanilla **(HTML, CSS y PHP)**.  
Se utiliza **Composer** para gestionar librerías PHP y, en particular, el cliente de autenticación de Google.

## Requisitos

Antes de comenzar asegúrate de tener instalado:

- [Node.js](https://nodejs.org/) (v16 o superior recomendado)
- [Composer](https://getcomposer.org/) (para instalar dependencias PHP)
- [XAMPP](https://www.apachefriends.org/) o cualquier servidor local con PHP 8+

## Instalación

1. **Clona este repositorio:**
git clone https://github.com/eemi1.git
cd tu-repo

2. **Dependencias necesarias:**
npm install
composer install
